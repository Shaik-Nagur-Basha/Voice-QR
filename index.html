Android Offline & APK Setup

This app runs 100% offline with an embedded QR generator:

  • Install on Android: Open in Chrome on Android and tap ⋮ → Add to Home screen.
  • Offline Voice Recognition: In Android Settings → Languages & Input → On-device speech recognition, download English for Airplane Mode use.
  • Export Native APK: Place this file in app/src/main/assets/index.html inside an Android WebView project.
